# АгроКонтур — многостраничный сайт дилера систем точного земледелия

## Локальный запуск
1. Откройте папку проекта в VS Code.
2. Запустите расширение **Live Server** (или любой локальный HTTP-сервер).
3. Откройте сайт по локальному URL.

## Настройка Formspree
На страницах форм добавлен маркер:

`<!-- ВСТАВЬТЕ СЮДА СВОЙ FORMSPREE ENDPOINT: https://formspree.io/f/XXXXXXXX -->`

Шаги:
1. Зарегистрируйтесь на Formspree.
2. Создайте форму и получите endpoint вида `https://formspree.io/f/XXXXXXXX`.
3. Подставьте endpoint в `action` каждой формы:
   - `contact/index.html`
   - `calc/index.html`
   - `product/index.html`
4. Проверьте отправку с локального сервера.

## Фоновый паттерн
Глобальный водяной знак техники находится в файле:
- `assets/img/agro-pattern.svg`

При необходимости замените его своим SVG/PNG, сохранив путь в `css/main.css`.
